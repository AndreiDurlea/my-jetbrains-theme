# Changelog

## 1.0.1
- Rename the themes. Deuterium now uses the `#141414` background and the Limelight accent; the `#0d0d0d` variant with the Infrared accent is Deuterium Classic (`andreidurlea.deuterium-classic`).
- Color keywords with the upright Deuterium red `#f57385` instead of the italic Lotus `#ff6188` and `#ff4c8f`.
- Paint tool window stripes and toolbar icon backgrounds in the window frame color instead of the editor background.

## 1.0.0
- Deuterium and Deuterium Lite UI themes for the Islands UI, each with an editor color scheme of the same name, packaged as a resource-only plugin for JetBrains IDEs from build 253 (2025.3).
- Syntax colors from Lotus Dark (Classic) (MIT, Brian Lai), with Deuterium colors for diagnostics, search, diff, console, Logcat and terminal.
