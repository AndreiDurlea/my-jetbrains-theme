# Changelog

## 2.0.0
- Replace the VS Code extension sources with a JetBrains theme plugin: Islands-based UI themes and editor schemes for Deuterium and Deuterium Lite, generated by `npm run package` into a resource-only JAR.
- Use Lotus Dark (Classic) syntax colors (MIT, Brian Lai), with Deuterium colors for diagnostics, search, diff, console, Logcat and terminal.
- Release the JAR to GitHub releases instead of publishing a VSIX to Open VSX and the VS Code Marketplace.
